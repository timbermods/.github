Timbermods makes mods for [Timberborn](https://timberborn.com/), built for version **1.1.2.4**. The [catalog](https://timbermods.github.io/) has a one-click download of each mod's latest release.

## The mods

## Install

1. **Download** the mod's ZIP from its Releases page, under **Assets** (not *Source code*).
2. **Close** Timberborn and extract the ZIP into `Documents\Timberborn\Mods`.
3. **Enable** the mod in the game's mod manager, and restart when prompted.

- Harmony and Mod Settings are separate mods from the Steam Workshop. Each mod above lists what it needs.
- Playing co-op? Every player installs the same version of the mod and runs the same game version.

## Help

Most mods' websites have an install guide, troubleshooting and an FAQ; the links above go straight to them. To report a problem, open an issue in the mod's GitHub repository.
