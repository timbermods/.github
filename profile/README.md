Timbermods makes mods for [Timberborn](https://timberborn.com/): more stable co-op, a colony for each co-op player, less lag in big colonies, mixed storage, shorter commutes, pinned work areas, better-timed meals for working beavers, and a swim-up pool bar. Everything here is built for Timberborn **1.1.2.4**, and the [catalog](https://timbermods.github.io/) has a one-click download of each mod's latest release.

## The mods

## Install

1. **Download** the mod's ZIP from its Releases page. Choose the file under **Assets**, not *Source code*.
2. **Extract** it into `Documents\Timberborn\Mods` while the game is closed.
3. **Enable** it in the game's mod manager and restart when prompted.

- Harmony and Mod Settings are separate mods from the Steam Workshop. Each mod above lists what it needs.
- Playing co-op? Every player installs the same version of the mod and runs the same game version.
- Builds marked **Beta** or **Preview** are early. Try them on a copy of a save first.
