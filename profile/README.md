Timbermods makes mods for [Timberborn](https://timberborn.com/): co-op stability, two-colony trading, big-colony performance, smarter storage and housing, beavers that eat before the shift, and a pool bar for tired beavers. Everything here is built for Timberborn **1.1.2.4**, and the [catalog](https://timbermods.github.io/) has a one-click download of each mod's newest release.

## Install

1. **Download** the mod's ZIP from its Releases page. Choose the file under **Assets**, not *Source code*.
2. **Extract** it into `Documents\Timberborn\Mods` while the game is closed.
3. **Enable** it in the game's mod manager and restart when prompted.

- Harmony and Mod Settings are separate mods from the Steam Workshop. Each mod above lists what it needs.
- Playing co-op? Every player must install the identical version of a mod, and run the same game version.
- Builds marked **Preview** are early. Try them on a copy of a save first.
